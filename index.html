AWS Knowledge Wall

Millionaire Edition - Created by Nwabueze Brent Ugoh

Project Documentation

Game Description: The AWS Knowledge Wall is a "Millionaire Edition" study tool that presents core infrastructure questions simultaneously. It provides lifelines like "50/50" and "Show Answer" to assist in learning.

Gameplay Instructions:

  • Select the best answer for each question card.
  • 50/50 Lifeline: Removes two incorrect answers from the current card.
  • Show Answer: Instantly highlights the correct choice.
  • Correct choices turn green; incorrect choices turn red.
  • Complete all questions to view your final score and rank.

Visual Concept:
